P2P Guardian V24.2.5 - Inno Setup Build

1. Install Inno Setup 7.x (64-bit recommended).
2. Open P2P_Guardian_V24_2_5_SETUP.iss in Inno Setup.
3. Build -> Compile.
4. The installer EXE is created in the configured Output folder.

The public source package does not contain Discord bot tokens,
personal Discord IDs, private channel IDs, API keys, passwords,
or webhooks.

Users provide their own Discord configuration during setup.

The installer supports both new installations and updates.
Existing local Discord configuration is preserved during updates.

The installer also includes the P2P Guardian support tools.

Note: this source was prepared for Inno Setup 7.x.
Compilation should be performed on Windows with Inno Setup installed.
